# Greenosa Digital — Brand Guidelines

An editorial, motion-led Svelte brand-guideline website built from Greenosa Digital's supplied identity assets and brand-guideline PDF.

Live site: https://tareqrahman23.github.io/greenosa-brand-guidelines/

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://127.0.0.1:4173`.

## Production build

```bash
pnpm build
pnpm preview
```

The site includes responsive desktop/mobile layouts, GSAP motion with reduced-motion support, and a downloadable copy of the complete PDF guidelines.
